# Claude & Soil

A fictional brand website for the worldbuilding project "Claude & Soil".

## Overview
This is a static site built with:
- HTML
- CSS
- JavaScript

## Structure
- `index.html`
- `css/style.css`
- `js/main.js`
- `assets/`

## Notes
- All products, prices, and brand elements are fictional.
- Images are stored under `assets/hero-group`, `assets/package-design`, and `assets/plated`.
- This site is intended for GitHub Pages deployment.
